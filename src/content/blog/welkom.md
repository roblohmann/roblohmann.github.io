# Welkom!

Dit is mijn eerste blog post in Astro. Astro is een fantastische static site generator die:

- Super snel is
- Standaard zero JavaScript naar de browser stuurt
- Markdown en MDX ondersteunt
- Gemakkelijk te gebruiken is

## Waarom Astro?

Astro maakt het bouwen van snelle websites ongelooflijk eenvoudig. Met content collections kan je je blog posts makkelijk organiseren en type-safe maken.

```typescript
const allPosts = await getCollection('blog');
```
